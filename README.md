
# Rock Paper Scissors

A simple Rock Paper Scissors game built as part of [The Odin Project](https://www.theodinproject.com/) JavaScript course.

## Features

- Play Rock Paper Scissors in your browser using UI buttons instead of typing in the console.
- See the running score and round results directly on the page.
- The first to reach 5 points wins the game, with a winner announcement.
- All game logic and UI handled in vanilla JavaScript.

## How to Play

1. Open `index.html` in your browser.
2. Click "Rock", "Paper", or "Scissors" to make your move.
3. The computer’s move and the result of each round is displayed.
4. Scores update after each round. When a player reaches 5 points, the winner is announced and play stops.

## Files

- `index.html` — Main HTML file with buttons and display areas
- `index.js` — JavaScript game logic and UI code
